## ✨ Features

| Feature | Description |
|---|---|
| 🌓 **Light & Dark Mode** | Instant theme switcher with smooth color transitions and `localStorage` preference persistence |
| 🌌 **Dynamic Particle Canvas** | Interactive HTML5 canvas with floating networked nodes that dynamically re-theme between light and dark modes |
| ⌨️ **Typewriter Hero** | Smooth animated role switcher cycling through developer passions and core skillsets |
| 🛡️ **Active Project Status** | Dedicated "In Development" pulsating badges highlighting ongoing AI security projects |
| 🃏 **Interactive 3D Tilt** | Physics-based perspective tilt on project and skill cards responding to mouse movement |
| 🔍 **Category Project Filter** | Real-time tabbed filtering for AI Security, Full-Stack, and AI/ML projects with animated transitions |
| 📄 **Embedded Resume** | Direct download button and viewer link for updated resume PDF |
| 📱 **100% Responsive** | Custom mobile drawer menu, scalable typography, and fluid CSS grid |

## 🏗️ Architecture & Tech Stack

```
portfolio-website/
│
├── index.html           # Semantic, accessible HTML5 structure with FontAwesome icons
├── style.css            # Custom CSS properties, Dark/Light modes, glassmorphism, responsive queries
├── script.js            # Particle canvas engine, typewriter, 3D card tilt, intersection observers
├── assets/
│   └── resume.pdf       # Embedded resume document
└── README.md            # Repository documentation
```

| Layer | Technology |
|---|---|
| **Structure** | Semantic HTML5 |
| **Styling** | Modern CSS3 (CSS Variables, Flexbox, CSS Grid, Glassmorphism) |
| **Interactivity** | Vanilla JavaScript (ES6+, HTML5 Canvas API, IntersectionObserver API) |
| **Typography** | Inter, Space Grotesk, JetBrains Mono (Google Fonts) |
| **Icons** | Font Awesome 6.5.1 |

## 🚀 Quick Start

To run this portfolio locally:

```bash
# 1. Clone repository
git clone https://github.com/Prasunnandi/portfolio-website.git
cd portfolio-website

# 2. Open in your browser
# On Windows PowerShell:
start index.html
```

Or serve with any static web server:
```bash
npx serve .
# or
python -m http.server 8000
```
