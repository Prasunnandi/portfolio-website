## 🚀 Quickstart

Run this portfolio locally:

```bash
# 1. Clone repository
git clone https://github.com/Prasunnandi/portfolio-website.git
cd portfolio-website

# 2. Serve locally
# Python:
python -m http.server 8000
# or Node.js:
npx serve .
```

Open `http://localhost:8000` in your web browser.
